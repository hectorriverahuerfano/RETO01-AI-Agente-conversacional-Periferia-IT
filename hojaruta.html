Hoja de ruta y checklist de arranque

Consigue cada recurso, márcalo y al final valida si ya puedes arrancar el reloj de 2 horas. Tu progreso se guarda en este navegador.

Nunca escribas aquí tu API key ni contraseñas. Este formulario solo registra si ya las tienes listas. La clave va en tu .env local y en el panel de Render.

1 · Proveedor de LLM y API key Obligatorio

Sin clave no hay agente en el link. Recomendado: Anthropic.

2 · GitHub y Render Obligatorio

Render mantiene un proceso vivo: sesiones en memoria y out/ funcionan. Sin link: −10 puntos.

3 · Runtime local Obligatorio

Detectado: Node v24.15, npm 11.12, git 2.54. Bun no está instalado.

4 · Fecha de referencia de vigencias Obligatorio

La Cámara de Comercio vence el 2026-09-30. Si la defensa es después y usamos la fecha real, todos los casos se bloquean y demo.ts deja de ser determinista.

5 · Protección del link Decisión

Un link público gasta tu clave. Una clave de acceso simple (documentada en el README) cuesta ~10 min.

6 · Alcance Decisión

Si el tiempo aprieta se recorta primero el bonus y luego el PDF. xlsx, paquete, confirmación y link no se tocan.

7 · Forma de entrega Obligatorio

Archivo: reto-01-<apellido>.zip

8 · Reloj de 2 horas Obligatorio

Lo ideal es tener los pasos 1–3 listos antes de iniciar el reloj.
